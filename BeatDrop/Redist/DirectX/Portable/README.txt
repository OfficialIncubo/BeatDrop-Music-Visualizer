In case you don't have access to install DirectX Web User Runtime, here is how to correctly install DirectX using a Portable method.

There are two different architectures: x86 as 32-bit and x64 as 64-bit. Open one of the folder with your BeatDrop architecture you have. This would solve the error with the code 0xc000007b (32-bit vs. 64-bit DLL mismatch or missing/corrupted DLL files).

Copy all the DLL files to your BeatDrop folder or in C:\Windows\System32\.
